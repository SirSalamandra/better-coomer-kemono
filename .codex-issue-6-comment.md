Overview da modificacao:

- Criei `EnrichmentPipeline` em `src/core/services/enrichmentPipeline.ts` para concentrar coordenacao de fetch, transformacao e persistencia de enrichment de artists e posts.
- `src/core/services/enrichmentService.ts` agora ficou fino: so delega para pipeline, sem repetir logica de rede/DB.
- `src/ui/management/utils/enrich.ts` foi refatorado para usar pipeline e manter apenas comportamento de UI (`loadData()` e `render()` depois de mudanca confirmada).
- Resolucao de host saiu da camada de UI e foi movida para `src/shared/utils/host.ts`, removendo dependencia indevida de `core` -> `ui`.
- Componentes e paginas que precisavam de host passaram a importar helper compartilhado.
- Testes foram atualizados para mockar pipeline no ponto certo e adicionei cobertura para wrapper de `enrichArtists`.

Resultado: enrichment ficou modulo mais profundo e reutilizavel, UI ficou mais burra, e acoplamento entre UI, fetch e IndexedDB caiu.

Validacao: `npm test` passou completo (12 suites, 172 testes).
