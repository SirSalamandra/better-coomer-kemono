# Extension Feature Ideas

## Enhancements to Existing Features

### 1. "Viewed" Status Improvements
- **Mark as Unread:** Add a button or option on a post to manually remove its "Viewed" status.
- **Hover for Details:** Show the date and time a post was first viewed when the user hovers over the "Viewed" tag.
- **Customizable Tags:** Allow users to change the text or color of the "Viewed" tag through the extension's settings.

### 2. Audio Player Upgrades
- **Playlist Support:** If a post contains multiple audio files, group them into a single playlist within one player, rather than showing multiple players.
- **Volume Memory:** Save and automatically apply the user's preferred volume level across all posts.
- **Keyboard Shortcuts:** Implement keyboard controls for play/pause, volume, and skipping tracks in a playlist.

## New Core Features

### 3. Image & Gallery Tools
- **Gallery/Slideshow Mode:** For posts with multiple images, add a button that opens a full-screen slideshow viewer with keyboard navigation.
- **Download All Button:** Add a button to download all images from a post, perhaps packaged in a `.zip` file named after the post or artist.

### 4. Content Filtering and Tagging
- **Custom Tags:** Allow users to create and apply their own tags to posts (e.g., "Favorite," "To-Download," "Read Later").
- **Filter by Tags:** Add controls to the page to show or hide posts based on the tags you've applied.
- **Highlight New Content:** On an artist's page, automatically highlight posts that have been published since the user's last visit.

## Data & Settings Management

### 5. A Useful Popup Menu
- The popup is currently a placeholder. You could transform it into a dashboard.
- **Recent Activity:** Show a list of the last 5-10 posts or artists you've visited.
- **Statistics:** Display fun stats like "Total Posts Viewed" or "Artists Tracked."
- **Settings Panel:** Make the popup the central place for all extension settings (customizing tags, enabling/disabling features, etc.).

### 6. Data Backup & Restore
- Add an option in the settings to export all extension data (viewed posts, tags, favorites) to a JSON or CSV file.
- Implement a restore function to import that data back. This is crucial for users who switch browsers or computers.

## Advanced Features

### 7. Favorite Artist System
- Allow users to mark specific artists as "Favorites."
- Create a special "Favorites Feed" page (accessible from the popup) that aggregates all recent posts from favorited artists into one place.
